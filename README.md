# Ajay — Soullit Design Portfolio

A responsive portfolio website for Ajay, built with HTML, CSS and vanilla JavaScript. Designed with a strict three-colour system:

- White `#FFFFFF` — primary background
- Charcoal `#171717` — typography and contrast
- Electric blue `#3155D9` — accent and calls to action

## Pages
- `index.html` — complete portfolio, about, services, selected work, experience, education, toolkit and contact
- `design.html` — graphic design project gallery
- `photography.html` — photography gallery
- `ui-ux.html` — UI/UX gallery

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy to GitHub Pages
1. Upload the contents of this folder to your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The site uses Google Fonts when an internet connection is available and falls back to system fonts otherwise. Project images are stored in the `Images` folder.
